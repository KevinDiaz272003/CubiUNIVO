CubiUNIVO

Sistema web para la gestión y reserva de cubículos de estudio en la Biblioteca de la Universidad de Oriente (UNIVO).

Descripción

Actualmente los estudiantes deben acudir personalmente a la biblioteca para consultar si existe un cubículo disponible. Esto provoca pérdida de tiempo e incertidumbre al momento de buscar espacios de estudio.

CubiUNIVO permite consultar la disponibilidad de los cubículos y realizar reservas de forma rápida mediante una plataforma web.

Tecnologías utilizadas

* PHP
* MySQL
* HTML5
* CSS3
* JavaScript
* Web Components
* XAMPP

Funcionalidades

 Estudiantes

* Inicio de sesión.
* Visualización de cubículos disponibles.
* Reserva de cubículos.
* Consulta de reservas realizadas.
* Cancelación de reservas.

 Administrador

* Visualización de todas las reservas.
* Gestión de reservas.
* Estadísticas generales del sistema.

 Instalación

 Requisitos

* XAMPP
* PHP
* MySQL

### Pasos

1. Copiar la carpeta CubiUNIVO dentro de:

C:\xampp\htdocs

2. Abrir phpMyAdmin.

3. Crear una base de datos llamada:

cubiunivo

4. Importar el archivo:

database/cubiunivo.sql

5. Iniciar Apache y MySQL desde XAMPP.

6. Abrir en el navegador:

http://localhost/CubiUNIVO
